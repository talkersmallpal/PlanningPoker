♠ Planning Poker

Planning Poker button for Jira

Start a session from any Jira filter, search or backlog page. The button collects the ticket links on the page and opens the Start page with them filled in. You then enter the admin password and press Start.

Planning Poker

Drag the button above to your bookmarks bar.

Install

  1. Show the bookmarks bar (Chrome / Edge / Firefox: Ctrl or Cmd + Shift + B; Safari: View, Show Favorites Bar).
  2. Drag the Planning Poker button onto the bar. If dragging does not work, create a bookmark manually, name it Planning Poker and paste the code below as its URL.
  3. Open a Jira page that lists tickets (narrow the filter first; every /browse/KEY-123 link on the page is used) and click the bookmark. If the page has no tickets, it shows a warning and, after you close it, opens this app's home page instead.

Base URL used: . If you move the app to another address, open this page from that address to get a new button.
